# Uso de Inteligência Artificial

Partes deste projeto foram desenvolvidas com apoio de ferramentas de IA generativa, em diferentes graus conforme a área, descrito abaixo — conforme as diretrizes da disciplina, que permitem o uso de IA generativa como ferramenta de apoio, desde que explicitado.

## Front-end — Erik da Silva Ribeiro

A estrutura base (HTML e CSS) foi escrita manualmente. IA generativa foi usada como apoio para a parte de JavaScript (ainda em aprendizado) e, posteriormente, para implementar grande parte das funcionalidades e componentes restantes, sempre a partir de decisões de design e comportamento definidas pela equipe.

## Back-end — Luigi Andrade Schiavone e Gustavo Rabello Silva

A estrutura base foi implementada pela equipe. IA generativa foi usada para completar funcionalidades que ainda faltavam, corrigir erros e implementar validações, sob orientação e revisão da equipe.

## Banco de dados — João Paulo de Oliveira Ribeiro

A modelagem e a implementação das coleções do MongoDB foram feitas manualmente, sem uso de IA.

## Documentação

A documentação técnica do projeto (os arquivos em `docs/`, este incluído) também foi escrita com apoio de IA generativa, a partir do que foi de fato implementado no código.

---

Em todos os casos, as regras de negócio, o fluxo do sistema e os testes finais de cada funcionalidade foram definidos e validados pela equipe.
